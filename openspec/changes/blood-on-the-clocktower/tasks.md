Every behaviour task writes its scenario tests first, named "Scenario: <title>" exactly as in the specs, from the THEN
clauses, and watches them fail for the right reason before the code. Copy is neutral German, no "!" and no emoji;
character names stay English with the TPI ability text quoted. Every test a unit breaks is fixed in that unit;
"unchanged and green" lists tests that must pass without changing their expectations. Shapes shared between units, the
fixtures and the owner of each test file: design.md → Contracts. Rules are proven in vitest, e2e proves flows and look:
BotC e2e uses only localStorage (`seedRoster`, `seedClocktower`), never the database; locators are exact-text and
scoped to `live(page)`; a test that sets its own viewport or uses only `request` runs in one project
(`test.skip(info.project.name !== …)`); geometry is measured in one `evaluate` after finite animations end; a phase
screen's primary action is measured on phone (header ~230px) before it is laid out; long tap-throughs set
`test.setTimeout` from the step count. Run `npm run build` before a scoped `npx playwright test <file>`; run
`proof:full` with `run_in_background` (~10 min), never two at once. Each unit fills only its own walk file; walks seed
their own state. No task is irreversible (no migration, data deletion, infra apply or publish), so no task carries ⚠.
