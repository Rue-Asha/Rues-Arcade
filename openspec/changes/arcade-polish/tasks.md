Every behaviour task writes its scenario tests first, named "Scenario: <title>" as in the specs, from the THEN
clauses, and watches them fail for the right reason before the code. Copy is neutral German, no "!" and no emoji.
Every test a unit breaks is fixed in that unit; "unchanged and green" lists tests that must pass without changing their
expectations. Shapes shared between units and the owner of each test file: design.md → Contracts. Archive rules are
canonical: no reducer changes. e2e on the shared DB uses exact-text locators and compares only its own rows; count
scenarios use `emptyServer` (fresh DB: codes 91, duck 60, most-likely 60, feud 247, imposter and wavelength 0, players 0)
and reduce data through the content/players API with `writeHeaders(origin)`. Run `npm run build` before a scoped
`npx playwright test <file>`; run `proof:full` with `run_in_background` (~9 min); long demo tap-throughs keep
`test.setTimeout` from the step count (~0.8s/step on phone). Each game keeps a non-empty demo script and
`data-demo=expected` on its board controls. Screenshots for Gate 2 come from the verifier's run and are not committed.
No task is irreversible (no migration, deletion of data, infra or publish).
